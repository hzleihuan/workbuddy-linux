## 新增 make fetch-dmg 目标（最小改动，make install 不变）
用户确认范围：新增 `make fetch-dmg`（通过官网 API 自动下载最新 DMG 到 `downloads/`），`make install` 保持"仅安装已构建包"不变。

实现：
- 新增脚本 `scripts/fetch-dmg.sh`：
  - API：`https://www.codebuddy.cn/v2/update?platform=workbuddy-darwin-x64`（可用 `WB_UPDATE_API` 覆盖）。
  - 从返回 JSON 解析 `url` 字段（`.zip` URL），改写为 `.dmg` 后缀，得下载地址。
  - `mkdir -p downloads`，文件名 `basename` 后若已存在则跳过（`Already present ... skipping`），否则 `curl -L` 下载。
- Makefile：`.PHONY` 增加 `fetch-dmg`；help 增加一行；新增目标 `fetch-dmg: bash scripts/fetch-dmg.sh`。

验证：`make check` 通过（`portability-check-ok`，脚本被 `bash -n` 校验）。实测 `make fetch-dmg` 解析出 `5.2.5.32793105` 并因已存在跳过下载。

注：最新稳定版 = 5.2.5.32793105（与 downloads/ 现有 DMG 一致）。
