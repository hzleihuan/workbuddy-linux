  - 菜单退出调 `app.quit()` → `before-quit` 处理器(19936)进入无超时的异步确认分支 `promptActiveTasksQuitConfirmation`(19951) 或 `promptDocumentPreviewQuitConfirmation`(19963)，`event.preventDefault()` 后等待 `daemonSessionQueries.getActiveSessions()` / `releaseTencentDocsPreviewContextsWithPrompt` 的 Promise —— Linux 上该 Promise 永不 resolve → 进程挂起不退。
  - X 按钮：窗口 close 处理(17289) `if (isMac || this.trayActive)` 命中 → preventDefault + hide 到托盘；`window-all-closed`(19810) 因 `isTrayActive` 提前 return → 也不退。
  - 修复：4 个补丁（均 markOptional，跨版本优雅降级）：A1/A2 在 before-quit 两分支条件加 `&& process.platform !== "linux"`（跳过异步确认，落入最终清理 19976→performQuitCleanup 10s 超时→finishQuit→app.exit(0)）；B1 把 close 处理 `if (isMac || this.trayActive)` 改为 `if (isMac)`（X 真正关闭窗口）；B2 把 window-all-closed `if (windowManager?.isTrayActive)` 改为加 `&& process.platform !== "linux"`（Linux 即使有托盘也退出）。`make build-app` 验证 4 项 linuxQuit* 全 true，产物级抽取确认注入。注：此改动使 Linux 上 X 不再最小化到托盘、直接退出（用户明确希望 X 能退出）。
